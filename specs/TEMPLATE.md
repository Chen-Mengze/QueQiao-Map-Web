# 单条 REQ 模板

复制下面整块到对应 `specs/<域>/spec.md` 末尾，替换尖括号占位；一个 REQ 一节，编号只增不复用。

```markdown
### REQ-<域>-<NNN> 一行标题（含关键数字/字面量）

**SHALL**：一句规范性陈述，写死义务与精确值（数字必须与 config 默认值 / 源码常量一致）。

**场景**（1–3 个）：
- 给定 <前置状态>，当 <动作>，那么 <可观测结果>。
- 给定 <边界/异常前置>，当 <动作>，那么 <兜底行为>。

**验证**：`TestClass#method`（测试方法带 `@Tag("REQ-<域>-<NNN>")`；冒烟类命名 `*SmokeTest`；CI 侧校验注明「CI jar 冒烟 / 架构守卫」）
```

写作要求：

- SHALL 用「必须/绝不」级强度；场景给定/当/那么各至少一个，覆盖正常 + 边界/失败路径。
- 数字与字面量（阈值、Hz、上限、id、sub_type、文件名格式）必须与 `common/src/main` 常量及 AGENT.md / docs/INTEGRATION.md 一致，写前核对。
- 「验证：」写计划中的测试类#方法即可（测试未落地时由 lead 汇总校正），但 @Tag id 必须与本 REQ id 完全一致。
